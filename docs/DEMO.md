# Demo mode

DEMO MODE is enabled by default (`DEMO_MODE=true`) and works without Firebase credentials or Gemini key.

Demo extraction uses `sample-data/extracted-json/demo_case.json` and produces a deterministic 120 sq. ft. discrepancy finding between:

- Sale deed: Survey No. 42/3, area 1,200 sq. ft.
- Khata record: Survey No. 42/3, area 1,080 sq. ft.

All sample values are fictional.
